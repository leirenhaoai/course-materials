## 二、三步跑起来

### 第 1 步：起后端

双击 `code/run.bat`，或者：

```bat
cd /d D:\系统分析与设计作业\code
python app\server.py
```

看到 `http://0.0.0.0:8000` 就成了。**注意是 `0.0.0.0`**（不是 `127.0.0.1`），这样手机才连得进来。

### 第 2 步：确认小程序指向的地址对

打开 `code/miniprogram/app.js`，第 1 行左右：

```js
const BASE = "http://10.102.71.59:8000";
```

这个 IP 必须是**电脑当前的局域网地址**。查法：

```bat
ipconfig | findstr IPv4
```

换网络了就重跑一次：

```bat
python tools\mp_setup.py
```

它会自动找本机 IP、改 `app.js`、打印下一步该做什么。

### 第 3 步：打开开发者工具

- 桌面快捷方式「微信开发者工具」→ 项目列表里选 **adc-patient**（已经导入过了）
- 或者：导入项目 → 目录选 `D:\系统分析与设计作业\code\miniprogram` → AppID 点「测试号」

模拟器里直接能点。改代码后工具会自动热重载。

## 三、手机真机怎么看

### 前提
**手机和电脑必须在同一个局域网**，且这个网里没有「AP 隔离」（公司/学校 WiFi 常见，会挡设备互访）。

现在用的是手机热点：电脑连 `Xiaomi 14` 的热点，电脑 IP `10.102.71.59`。

### 步骤
1. 开发者工具顶部点 **真机调试**（不是「预览」——预览要走域名校验）
2. 手机微信扫弹出的二维码
3. 手机上会打开你的小程序

### 三种结果对应三种问题

| 手机上的现象 | 原因 | 怎么办 |
|---|---|---|
| 能看到登录页、能登录、有数据 | 通了 | 不用做任何事 |
| 白屏 / `request:fail` | 微信没跳过域名校验 | 右上角「详情」→「本地设置」→ 勾 **不校验合法域名、web-view、TLS 版本以及 HTTPS 证书** |
| `timeout` / 一直转圈 | 手机连的不是这个网 | 手机也连同一个热点；或改连电脑所在的那个 WiFi 后重跑 `mp_setup.py` |

### 还是不通，按顺序排查
1. 电脑上打开浏览器访问 `http://10.102.71.59:8000/api/ping`，应返回 `{"ok": true, ...}`
   - 不通 → 后端没起来，或者监听的不是 `0.0.0.0`
2. 手机浏览器访问同一个地址
   - 浏览器能开、小程序不能 → 一定是第 2 种情况（域名校验），勾那个勾
   - 浏览器也开不了 → 网络问题，换网
3. 防火墙：`ADC-patient-8000` 这条入站规则要存在且是 Allow
   ```powershell
   Get-NetFirewallRule -DisplayName "ADC-patient-8000"
   ```

## 四、换成你自己的正式 AppID

测试号能用，但左下角会显示「测试号」。想换成自己的：

1. 打开 https://mp.weixin.qq.com → 立即注册 → 小程序
2. 邮箱 + 密码 → 选「个人」主体 → 身份证 + 人脸 + 短信
   - **类目先随便选**（比如「工具」），医疗类目等真要上线时再补资质
3. 注册完在「开发 → 开发管理 → 开发设置」里拿到 **AppID**（`wx` 开头 18 位）
4. 改 `code/miniprogram/project.config.json`：
   ```json
   "appid": "wx你的真实appid"
   ```
5. 开发者工具里项目会提示重新授权，点确认

**注册不需要备案，也不需要服务器。** 备案是「发布上线」那一步才要的，作业用不到。

## 六、几个要知道的设计点

**为什么用 Bearer token**
小程序没有 Cookie，所以用 `Authorization: Bearer <session_id>`，`session_id` 就是网页端 `SESSION` 表里那条。两边共用一套登录状态管理，互不踢人。

**为什么 `h.form()` 要改**
原来只认 `application/x-www-form-urlencoded`，而 `wx.request` 默认发 `application/json`，导致所有 POST 拿到空 dict、登录永远报「请填写登录名和口令」。现在 `form()` 会自动判断 Content-Type 和 body 首字符。

**余位是怎么算的**
只有一个口径：`IFNULL(is_void,0)=0 AND status IN ('已预约','已到诊')`。而且**今天要 `slot_end` 没过去**才算——这条是 2026-11-18 真机测试才补的（那次 16:41 了，09:00–12:00 的班还显示「剩 22 位」，点进去才被拒）。

**数据是真的**
所有数字来自 `data/adc.db`，不是写死的假数据。要重置成初始演示数据：删掉 `data/adc.db` 再跑 `run.bat`。

- **没在真实诊所跑过**：功能是完整的，但真实业务的边角（爽约退款、跨店转诊的纸质流程）没经历过
