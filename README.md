# 安德鲁牙科连锁店诊疗管理系统 · 业务建模与需求说明

系统分析与设计课程作业。案例：安德鲁牙科连锁店（Andrew's Dental Chain，ADC）——广东省 15 家牙科诊所，计划三年内翻一番。

文档交付 **A-业务建模** 与 **B-需求** 两段建模成果，并按课件延伸 **C-分析**（分析类图）与 **D-设计**（从类图到关系数据库）。
